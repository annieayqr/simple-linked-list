# Simple Linked List in Python
![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)
![GitHub](https://img.shields.io/badge/license-MIT-green.svg)
![Status](https://img.shields.io/badge/status-complete-brightgreen.svg)

A clean, minimal implementation of a singly linked list with just four essential operations.

## Features
- **Insert** - Add values to the end of the list
- **Find** - Check if a value exists in the list  
- **Delete** - Remove a value from the list
- **Print** - Display all values in the list
