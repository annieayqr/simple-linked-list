# Doubly Linked List in Python


A clean implementation of a doubly linked list with mixed iterative and recursive operations. Fixed critical bugs in recursive search and display formatting.

## Features
- **Insert** - Add nodes to end (iterative)
- **Find** - Search for values (recursive, no infinite loops)
- **Delete** - Remove nodes from any position
- **Print** - Display values with clean formatting
- Handles all edge cases (empty list, head/tail deletion)

## Files
- `node.py` - Node class with value, prev, and next pointers
- `linked_list.py` - LinkedList class with all operations
- `main.py` - Simple demonstration
- `test.py` - Complete test suite

## Quick Start
```bash
python3 main.py
