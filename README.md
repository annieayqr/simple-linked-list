# Doubly Linked List in Python

A clean implementation of a doubly linked list with mixed iterative and recursive operations.

## Features
- **Insert** - Add nodes to end (iterative traversal)
- **Find** - Search for values (recursive algorithm)  
- **Delete** - Remove nodes from any position (iterative)
- **Print** - Display all values (iterative traversal)
- Handles all edge cases (empty list, head/tail deletion)

## Quick Start
```bash
python3 main.py
